# ONTON Project Goals: Q2 2026 Roadmap

**Theme:** "Aggressive Growth & Decentralization"

Aligned with the user's strategic vision, these goals prioritize technical stability, massive user acquisition, and the shift towards community-led governance.

## 🧱 Goal 1: Technical Stability (The Foundation)
**Objective:** Ensure the platform is rock-solid to handle "Huge Traffic" without degradation.
*   **Key Result 1.1:** **Refactor Core Routers**: Decompose `events.ts` (42KB+) and `campaignRouter.ts` into testable, modular Services to prevent regression bugs.
*   **Key Result 1.2:** **Eliminate Polling**: Migrate 100% of critical "Money Flows" (Minting, Payments) to Event-Driven Architecture (RabbitMQ) for instant processing.
*   **Key Result 1.3:** **automated QA**: Achieve >80% Integration Test coverage for the Core Order Lifecycle (Create Order -> Pay -> Mint -> Check-in).

## 📣 Goal 2: Reactivate & Multiply Organizers (The Engine)
**Objective:** Wake up dormant organizers and arm them with tools to host more events.
*   **Key Result 2.1:** **Organizer "Win-Back" Campaign**: specific features to re-engage past hosts (e.g., "One-Click Duplicate Event", simplified Telegram broadcasting).
*   **Key Result 2.2:** **"Organizer Pro" Tools**: Launch advanced analytics (Sales/Show-rates) to give organizers value beyond just ticketing.
*   **Key Result 2.3:** **Community Hubs**: Deploy persistent DAO Profile Pages where organizers can build a following independent of individual events.

## 📈 Goal 3: Drive Massive Traffic (The Fuel)
**Objective:** Open the floodgates for user acquisition, leveraging the ONION token.
*   **Key Result 3.1:** **Unified Web Discovery**: Launch the "Luma-like" SEO-optimized web platform so every event page ranks on Google, driving organic traffic outside Telegram.
*   **Key Result 3.2:** **Viral Loops**: Implement "Share-to-Earn" features where users earn ONION for valid referrals (using the Affiliate System).
*   **Key Result 3.3:** **Cross-Community Quests**: Partner with top TON projects for joint "Proof-of-Action" campaigns that drive their users to ONTON.

## 🗳️ Goal 4: Launch Decentralized Decision Making (The Future)
**Objective:** Empower the community to steer the platform.
*   **Key Result 4.1:** **Governance Portal**: Build a "Proposal & Voting" UI within the Mini App where ONION holders vote on feature requests (e.g., "Which chain to support next?").
*   **Key Result 4.2:** **Snapshot Integration**: Link ONION holdings to voting power (Quadratic Voting support).
*   **Key Result 4.3:** **Transparency Dashboard**: Real-time view of Treasury usage and platform metrics to inform voter decisions.

## 🧅 Cross-Cutting: ONION Token Utility
**Objective:** Increase Demand & Utility (Token is LIVE).
*   **Strategy:** Every goal above must consume or lock ONION.
    *   *Stability:* Validators stake ONION? (Long term).
    *   *Organizers:* Stake ONION to unlock "Pro" analytics or feature events.
    *   *Traffic:* Spend ONION to boost events on the homepage.
    *   *Governance:* Vote weight = ONION held.
