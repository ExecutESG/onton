ONTON Telegram Bot Service Overview

The telegram-bot service is a specialized Node.js application responsible for all direct interactions with the Telegram Platform API. It works in two directions: handling user commands and providing an internal API for other services to send messages.

1. High-Level Architecture

graph TD User((Telegram User)) -->|/start| Grammy[Grammy Bot Logic] Grammy -->|Process| Handlers[Command Handlers] Handlers -->|Read/Write| DB[(PostgreSQL)] MiniApp[Mini App Service] -->|HTTP POST| Express[Internal Express API] Express -->|Send Message| TG_API((Telegram API)) TG_API -->|Notify| User

2. Technology Stack

  • Runtime: Node.js (TypeScript)
  • Bot Framework: Grammy
  • API Server: Express.js
  • Database: PostgreSQL (Direct connection via pg) & Redis (Session storage)
  • Storage: MinIO (S3) for file uploads

3. Directory Structure

telegram-bot/

4. Internal API Endpoints

The telegram-bot exposes an HTTP server (default port 3333) strictly for internal use by the mini-app or workers.

Method Endpoint Description
POST /send-message Sends a text message to a user.
POST /send-file Uploads and sends a file to a user.
POST /generate-qr Generates a QR code for a specific link.
POST /share-event Sends an event card to a user.

5. How it runs

The src/main.ts file does two things in parallel:

  1. Starts the Bot: bot.start() (Long polling mode).
  2. Starts Express: app.listen(3333) (Internal API).
