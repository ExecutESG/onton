# End-to-End (E2E) Testing Strategy

## Overview
This directory contains the E2E testing infrastructure for the ONTON Mini App and Website.
We use **Playwright** for browser automation and **Jest** for API integration testing.

## Phase 2 Roadmap
1.  **Smoke Tests**: Verify critical paths (Landing Page, Health Checks).
2.  **API Integration**: Verify backend logic without browser overhead.
3.  **Critical Flows**: Event Registration, User Profile Updates.
