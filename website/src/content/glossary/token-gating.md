> **Definition:**
> **Token Gating** is a decentralized access-control mechanism that grants or restricts entry to private community chats, exclusive physical event areas (such as speaker dinners or VIP lounges), and digital platforms based on whether a user's cryptocurrency wallet contains specific tokens or NFTs.

---

## Token Gating in ONTON
ONTON modernizes token gating for Telegram by combining smart contract checks with automated bot permissioning:
- **Instant Admittance:** When a user acquires an event ticket via [telegram-stars](/resources/glossary/telegram-stars) or TON, the gating bot generates an ephemeral, single-use Telegram invite link.
- **Anti-Leak Defense:** Static links that can be forwarded or leaked to third parties are completely eliminated; unauthorized clickers are rejected.
- **Dynamic Revocation:** If a ticket is refunded or invalidated, the bot programmatically removes the user from all associated event channels.
